# Related software

The following projects cover patent data preparation, citation analysis or reproducible research tooling. Links identify the repository snapshots consulted on 2026-10-09; they are references rather than runtime dependencies.

- [Patent2net/P2N-v3](https://github.com/Patent2net/P2N-v3/tree/43fc9500fcb65b364bd34c255e235efc4b9670b4): 专利采集与统计分析套件.
- [JYProjs/patentpy](https://github.com/JYProjs/patentpy/tree/be573fcbeb0b05abe4541b3f15dcb9ef9434e538): USPTO数据转表格的Python包.
- [cverluise/PatCit](https://github.com/cverluise/PatCit/tree/a2a5d7fa6664b2f33edfe60d353c13bf5f97fb84): 专利非专利文献引用提取/增强.
- [cortext/patstat](https://github.com/cortext/patstat/tree/ae02ee130ecfe21cef3096a73e0a167fdee22481): PATSTAT清洗与增强SQL脚本.
- [volfpeter/uspto-patent-citation-graph](https://github.com/volfpeter/uspto-patent-citation-graph/tree/9f24422d62fedd38ebcbbf7437bb5960abf78bd5): 按需采集专利引用图.
- [SciSciCollective/pyscisci](https://github.com/SciSciCollective/pyscisci/tree/acd38735ae1b23cf8b668e8947ccd833ca60ccac): 科研计量指标与网络分析库.
- [dspinellis/alexandria3k](https://github.com/dspinellis/alexandria3k/tree/479a00689464c41837096a86f457b32f1d48ce87): 可复现计量研究的CLI与Python接口.
- [mirkolai/pybiblionet](https://github.com/mirkolai/pybiblionet/tree/045f250381a8588966c47d2139be6105a2c3347c): 文献引文与合作网络指标.
- [KonstantinosPetrakis/PatentInspector](https://github.com/KonstantinosPetrakis/PatentInspector/tree/1823e25ee697ce3720aa1a5f5a6f63521ac1767e): Django/Vue专利分析Web应用.
- [scientific-python/cookie](https://github.com/scientific-python/cookie/tree/55ef55c2b406c7a4a2244ff246506d823e640ad6): 科学Python工程指南与模板.
- [timtroendle/cookiecutter-reproducible-research](https://github.com/timtroendle/cookiecutter-reproducible-research/tree/fb6325cc343a852e995e63cb8f3bb0db24a255f4): 可复现研究目录与报告流程.
- [mtcberlin/epo-tip-svelte-patstat-explorer](https://github.com/mtcberlin/epo-tip-svelte-patstat-explorer/tree/e00a727ddde542dbb4cff00f1fb1d6d96fef4ff6): PATSTAT交互探索界面.

Patent Diffusion Lab focuses on dated patent-family milestones, matched comparisons and opportunity-conditioned field references. Its CLI, local browser interface and reports share the same computational core.
